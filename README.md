# Idle FBO website

The home, privacy policy and support pages for Idle FBO, served by GitHub Pages at
https://chanjp3.github.io/idle-fbo-site/. The game's Settings and the store listings link to
`/privacy` and `/support`.

Plain HTML and CSS, no build step and no third-party requests: the fonts (Barlow Condensed and
Rubik, under the SIL Open Font License; see `assets/fonts`) and the icon are served from here.
